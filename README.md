## ⚙️ Getting Started

Follow these steps to get the project up and running on your local machine.

### Prerequisites

You must have [Node.js](https://nodejs.org/) and npm installed.

### Installation & Running

1.  **Clone the repository (or create the files manually):**
    ```sh
    git clone [https://your-repo-url.com/](https://your-repo-url.com/)
    cd your-project-folder
    ```

2.  **Install dependencies:**
    This will install Gulp and all necessary plugins listed in `package.json`.
    ```sh
    npm install
    ```

3.  **Run the development server:**
    This command executes the default Gulp task, which builds the site, starts a local server, and watches for any file changes.
    ```sh
    npm start
    ```

The site will be available at `http://localhost:3000`.
